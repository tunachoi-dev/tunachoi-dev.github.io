# \[Java] Math Operations
## 1. 연산자(Operator)
지난 포스팅에서 데이터를 담는 '상자(변수)'를 만들었다면, 이제 그 상자에 든 데이터를 가지고 계산을 할 차례입니다. `+`, `-`, `*`, `/` 처럼 계산을 수행하는 기호를 **연산자(Operator)** 라고 하고, 계산 대상이 되는 숫자를 **피연산자(Operand)** 라고 합니다.

---
## 2. 산술 연산자 (Arithmetic Operators)
우리가 수학 시간에 배운 사칙연산과 거의 똑같습니다. 하지만 프로그래밍이기 때문에 주의해야 할 **'자료형의 함정'** 이 하나 숨어있습니다.
### 2.1. 기본 연산
- `+`(더하기), `-`(빼기), `*` (곱하기)
- `/`(나누기), `%`(나머지)

**예제 코드**
```java
public class OperatorEx1 {
	public static void main(String[] args) {
		int num1 = 10;
		int num2 = 3;
		
		System.out.println(num1 + num2);  // 13
		System.out.println(num1 - num2);  // 7
		System.out.println(num1 * num2);  // 30
		
		System.out.println(num1 / num2);  // 3  (10 나누기 3의 '몫')
		System.out.println(num1 % num2);  // 1 (10 나누기 3의 '나머지')
	}
}
```
### 2.2. 주의할 점 (int형 나눗셈)
수학에서 `5 / 2`는 `2.5`입니다. 하지만 자바의 `int`끼리 계산하면 결과가 다릅니다,

```java
int num1 = 5;
int num2 = 2;
System.out.println(num1 / num2);  // 2.5가 아니라 '2'가 출력됩니다.
```
- **이유**: `int`는 정수만 담을 수 있는 상자입니다. 소수점 이하(`0.5`)는 버려집니다.
- **해결:** `2.5`라는 정확한 결과를 얻고 싶다면 형변환(Type Casting)을 통해 실수형(`double`)으로 바꿔서 계산해야 합니다. (이건 추후 Type Casting에서 자세히 다루겠습니다.)

## 3. 문자열 더하기
자바의 `+` 연산자는 조금 특별합니다. 숫자뿐만 아니라 **문자열(String)** 도 더할 수 있기 때문입니다. 규칙은 아주 간단합니다. **"문자열에 더하는 건 뭐든지 문자열이 된다"** 는 것입니다.

**예제 코드**
```java
// 1. 문자열끼리 더하기
String str1 = "hello ";
String str2 = "tunachoi";

// 2. 문자열과 숫자 더하기
String str3 = "my age is " + 28;
System.out.println(str3);  // "my age is 28" (숫자 28이 문자열 "28"로 변신)
```

**주의할 점 (순서가 중요)** 계산은 왼쪽에서 오른쪽으로 진행됩니다.
1. `10 + 20 + "점"` -> `30` + `"점"` -> **"30점"** (원하는 결과)
2. `"점수: " + 10 + 20"` -> `"점수: 10"` + `20` -> **"점수:1020"**

숫자 계산을 먼저 하고 싶다면 **괄호`()`** 로 감싸주세요.

## 4. 연산자 우선순위
`1 + 2 * 3`의 결과는 무엇일까요? 당연히 곱셈(`*`)을 먼저 계산하니 `7`입니다. 자바도 수학과 똑같은 우선순위를 가집니다. 하지만, 복잡한 식에서는 어떻게 해야 할까요?

## 4.1. 우선순위
우선순위가 높은(먼저 계산되는) 순서대로 나열하면 다음과 같습니다. 다 외울 필요는 없고 **흐름만** 느껴보세요.
1. **최상위:** `()` 괄호
2. **단항:** `++`, `--`, `!`
3. **산술:** `*`, `/`, `%` (곱하기, 나누기, 나머지)
4. **산술:** `+`, `-` (더하기, 빼기)
5. **비교:** `>`, `<`, `==`
6. **논리:** `&&`, `||`
7. **대입:** `=`

### 암기하지 말고 괄호`()`를 쓰세요
개발자들은 연산자 우선순위표를 달달 외우고 다니지 않습니다. **애매하면 무조건 괄호 `()`를 쓰세요.**
- `int result = 2 * 2 + 3 * 3;` (x) 한눈에 안 들어옵니다.
- `int result = (2 * 2) + (3 * 3);` (o) 명확하고 유지보수하기 좋습니다.

## 5. 증감 연산자
프로그래밍을 하다 보면 `num = num + 1` 처럼 값을 1씩 늘리거나 줄일 일이 정말 많습니다. 이걸 줄여 쓴게 증감 연산자입니다.
- `++`: 1증가
- `--`: 1감소
### 5.1. 전위(Prefix)와 후위(Postfix)
`++`가 앞에 붙느냐 뒤에 붙느냐에 따라 **타이밍**이 달라집니다.
- `++num`(전위): "일단 나부터 1증가시켜! 그리고 나서 써."
- `num++`(후위): "일단 지금 값 쓰고, 나중에 1 증가시켜."

**예제 코드**
```java
int num1 = 1;
int num2 = 0;

num2 = ++num1;  // num1가 먼저 2가 되고, 그 다음 num2에 대입 (결과: num1 = 2, num2 = 2)
num2 = num1++;  // num1(2)를 먼저 넣고, 나중에 num2가 3이 됨 (결과: num1 = 3, num2 = 2)
```

## 6. 비교와 논리
조건문(`if`)을 배우기 위한 필수 코스입니다. 결과는 항상 참(`true`) 아니면 거짓(`false`)입니다.
### 6.1. 비교 연산자
- `>` : 크다 (초과)
- `<` : 작다 (미만)
- `>=` : 크거나 같다 (이상)
- `<=` : 작거나 같다 (이하)
- `==` : **같다**
- `!=` : **다르다** (`!`는 NOT을 의미)

**예제 코드**
```java
int num1 = 10;
int num2 = 20;

// 1. 크기 비교
System.out.println(num1 > num2); // false (10은 20보다 크지 않음)
System.out.println(num1 < num2); // true (10은 20보다 작음)
System.out.println(num1 >= 10); // true (10은 10보다 크거나 같음)
System.out.println(num2 <= 20); // true (20은 20보다 작거나 같음)

// 2. 동등 비교
System.out.println(num1 == num2); // false (10과 20은 같지 않음)
System.out.println(num1 != num2); // true (10과 20은 다름)
```

### 6.2. 대입(`=`)과 비교(`==`) 구분하기
모양이 비슷해서 헷갈리는 부분입니다.
- `=`(대입 연산자): "변수라는 상자에 값을 **집어넣어라**"
- `==` (비교 연산자): "좌우의 값이 **똑같니?**"

### 6.3. 문자열 비교의 함정 (== vs equals)
숫자는 `==`로 비교하면 되지만, **문자열(String)은 절대로 `==`로 비교하면 안 됩니다.**

자바에서 문자열 변수는 실제 글자를 담는 게 아니라, 글자가 저장된 **'메모리 주소'** 를 담고 있습니다. 그래서 `==`를 쓰면 "내용이 같은가?"를 묻는 게 아니라 **"주소(위치)가 같은가?"** 를 묻게 됩니다.

```java
String str1 = "Java";
String str2 = new String("Java");  // 새로운 주소에 만들어진 "Java"

// X 틀린 방법: 주소를 비교하게 됨
System.out.println(str1 == str2);  // false (내용은 같은데 다르다고 나옴)

// O 맞는 방법: 내용을 비교함
System.out.println(str1.equals(str2));
```

### 6.4. 논리 연산자
여러 조건을 합칠 때 씁니다.
- `&&`(AND): 둘 다 참이어야 참
- `||`(OR): 둘 중 하나만 참이어도 참
- `!`(NOT): 반대로 뒤집기 (True -> False, False -> True)

## 7. 종합 예제
배운 내용을 코드로 정리해보겠습니다.

```java
package operator;

public class OperatorEx {
	public static void main(String[] args) {
		int num1 = 5;
		int num2 = 2;
		
		// 1. 산술 연산 (나눗셈 주의)
		System.out.println(num1 / num2);  // 2 (소수점 버림)
		System.out.println(num1 % num2);  // 1
		
		// 2. 문자열 더하기
		String msg = "Result: " + (num1 + num2);  // 괄호 없으면 "Result: 52"가 됨
		System.out.println(msg);  // "Result: 7"
		
		// 3. 비교 연산 (문자열은 equals)
		String str1 = "java";
		boolean isMatch = str1.equals("java");
		System.out.println(isMatch);  // true
		
		// 4. 복합 대입 연산자 (축약형)
		num1 += 10;  // num1 = num1 + 10; 과 같음
		System.out.println(num1);  // 15
	}
}
```

**추가 팁**
코드를 짤 때 가장 중요한 건 **'단순함'** 과 **'명확함'** 입니다.
- 코드를 줄이려고 복잡한 연산자 순서를 이용하기보다, 괄호 `()`를 써서 누가 봐도 알기 쉽게 만드는 습관을 들이세요.
- 문자열 비교는 `==` 대신 `.equals()`를 쓴다는 점, 꼭 기억해두세요
