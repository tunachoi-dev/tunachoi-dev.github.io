# \[SQL] What are Relational Databases?
데이터베이스를 처음 배운다면 반드시 알아야 할 개념이 있습니다. 바로 **관계형 데이터베이스(RDBMS)** 입니다. 오늘날 대부분의 서비스가 이 구조 위에서 돌아갑니다. 이 글에서는 RDBMS가 무엇인지, 어떤 원리로 작동하는지 차근차근 살펴봅니다.

---
## 1. 관계형 데이터베이스(RDBMS)의 정의 및 유래
관계형 데이터베이스는 1970년 **E.F.Codd**가 제안한 관계형 모델을 기반으로 합니다. 서로 연관된 데이터 포인트들을 저장하고, 이에 대한 효율적인 접근을 제공하는 시스템입니다.

---
## 2. 구조적 특징
- **표(Table) 기반 조직**: 데이터를 행(Row)과 열(Column)로 구성된 표 형태로 관리하여 구조를 명확히 합니다.
- **관계(Relationship) 설정**: 테이블 간의 관계를 맺음으로써 복잡한 쿼리 수행과 유기적인 데이터 검색이 가능해집니다.

---
## 3. 5대 핵심 기능
- **표준 SQL 사용**: 데이터 쿼리 및 관리를 위해 구조화된 질의 언어인 **SQL**을 사용합니다.
- **ACID 트랜잭션 지원**: 원자성, 일관성, 고립성, 지속성을 통해 어떤 상황에서도 데이터의 신뢰성을 보장합니다.
- **데이터 무결성 보장**: 기본 키(PK), 외래 키(FK) 등의 **제약 조건(Constraints)** 을 통해 데이터의 정확성을 강제합니다.
- **정교한 데이터 추출**: 테이블 간의 관계를 활용하여 대규모 데이터셋에서도 원하는 정보를 정확하게 찾아냅니다.
- **확장성 및 다중 사용자 지원**: 여러 사용자가 동시에 접속하는 환경에서도 안정적인 성능과 데이터 일관성을 유지합니다.

---
## 4. 주요 RDBMS 예시
- **MySQL**: 웹 애플리케이션에서 가장 널리 사용되는 오픈 소스 시스템입니다.
- **PostgreSQL**: 확장성과 표준 준수 기능이 뛰어난 오픈 소스 데이터베이스입니다.
- **Oracle**: 대규모 기업용 시스템에서 선호되는 강력한 성능의 상용 데이터베이스입니다.
- **Microsoft SQL Server**: 윈도우 환경 및 기업용 솔루션에 최적화된 시스템입니다.
