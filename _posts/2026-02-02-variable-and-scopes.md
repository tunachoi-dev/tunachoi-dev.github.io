# 1. 변수(Variable)
프로그래밍을 하다 보면 숫자나 문자 같은 데이터를 잠시 저장해둬야 할 때가 많습니다. 이때 수학에서의 변수처럼 '변하는 수'라고만 생각하기보다, **"값을 담는 딱 하나의 메모리 상의 공간"** 이라고 이해하는 게 더 정확합니다.
- **상자의 규칙**: 이 상자에는 딱 하나의 값만 들어갑니다.
- **덮어쓰기** : 이미 값이 있는 상자에 새 데이터를 넣으면? 예전 데이터는 사라집니다.

---
# 2. 변수 만들기
상자를 만들고(선언), 처음으로 물건을 채우는(초기화) 과정은 아주 중요합니다.
## 2.1. 선언(Declaration)
`int age;` 라고 치는 순간, 컴퓨터는 "정수를 담을 `age`라는 이름의 공간을 마련해야겠구나!"라고 알아듣습니다. 여기서 `int`는 상자의 종류(타입)를, `age`는 상자의 이름이 됩니다.
## 2.2. 초기화(Initialization)
상자를 만들었다면 사용하기 전에 꼭 비우거나 새로 채워야 합니다.
- **왜 초기화가 필수인가요?** 메모리는 여러 프로그램이 나눠 쓰는 공공시설 같습니다. 다른 프로그램이 쓰다 버린 **'쓰레기값(Garbage Value)'** 이 남아있을 수 있습니다.
- **대입 연산자(`=`)** 자바에서 `=`은 "같다"가 아니라 **'오른쪽 값을 왼쪽 상자에 집어넣어라"** 는 뜻입니다.

---
# 3. 예제
실제 코드가 어떻게 돌아가는지 확인하겠습니다.
```java
class VarEx {
	public static void main(String[] args) {
		int year = 0;  // 1. 선언과 동시에 0으로 초기화
		int age = 27;  // 2. 나이 상자에 27를 담음
		
		System.out.println(year);  // 0 출력
		System.out.println(age);  // 27 출력
		
		// 3. age에 1999을 더해 year에 저장 (계산 순서: 우측 -> 좌측)
		year = age + 1999;  // 27 + 1999 -> 2026가 year에 저장됨
		
		// 4. age 값을 1 증가시키기
		age = age + 1;  // 현재 age(27)에 1을 더해 다시 age에 넣음 (이제 28)
		
		System.out.print(year);  // 2026 print -> 줄바꿈 없음
		System.out.print(age);  // 28
	}
}
```
`println()`은 출력 후 줄을 바꾸고, `print()`는 줄 바꿈 없이 옆으로 쭉 붙여서 출력합니다.

# 4. 이름 짓기(Naming)
우리가 만드는 모든 이름(식별자)은 서로 구별되어야 합니다. 규칙은 엄격하지만, 관례를 따르면 훨씬 '프로' 같아 보입니다.

## 절대 안 되는 규칙 (컴파일 에러)
자바 컴파일러가 "이건 이름으로 쓸 수 없어!"라고 컴파일 에러를 표시합니다.

- **숫자 시작:** `7up` (x) -> `up7` (o)
- **특수문자:** `_`와 `$`만 허용합니다. (예: `W!ow`은 안 됩니다!)
- **예약어:** 자바가 이미 예약한 `int`, `true`, `class` 등은 이름으로 쓸 수 없습니다.
### 예제 코드
```java
// 1. 숫자로 시작할 수 없습니다.
int 7up;  // (x) 에러 발생
int up7;  // (o) 숫자가 뒤에 오는 건 괜찮습니다.

// 2. 예약어(이미 용도가 정해진 단어)는 사용할 수 없습니다.
int class;  // (x) 에러 발생 class는 클래스를 선언할 때 쓰는 에약어입니다.
int Class;  // (o) 대소문자를 구분하기 때문에 이건 가능하지만, 권장하지 않습니다.

// 3. 특수문자는 `_`와 `$`만 허용합니다.
int user#id;  // (x) 에러 발생! #은 사용할 수 없습니다.
int _id, $pr;  // (o) _와 $로 시작하거나 포함하는 건 가능합니다.
```
## 지키면 좋은 관례 (Convention)
반드시 지켜야 하는 건 아니지만, 전 세계 자바 개발자들이 암묵적으로 지키는 약속입니다.

- **클래스**는 대문자로 시작하기(`MyClass`)
- **변수와 메서드**는 소문자로 시작하고 단어 조합 시 대문자 섞기(`lastIndexOf`)
- **상수**는 전부 대문자로 쓰고 언더바로 구분하기(`MAX_VALUE`)
### 예제 코드
```java
// 1. 클래스 이름의 첫 글자는 항상 대문자로 합니다.
class MyProject {}
class VarEx {}

// 2. 변수와 메서드 이름의 첫 글자는 항상 소문자로 합니다.
int age = 27;
int lastIndexOf = 10;  // 여러 단어가 합쳐지면 단어 첫 글자를 대문자로(camelCase)

// 3. 상수의 이름은 모두 대문자로 하고, '_'로 구분합니다.
final int MAX_SPEED = 120;  // 'final'이 붙으면 값이 변하지 않는 상수입니다.
final double PI = 3.14;
```
## 추가 팁
이름을 지을 때 가장 중요한 건 **'의미'** 입니다.
- `int a = 10;` (x) 나중에 보면 이 `a`가 나이인지, 사과 개수인지 알 수 없습니다.
- `int appleCount = 10;` (o) 이름만 보고도 "사과가 10개 있구나!"라고 바로 알 수 있습니다.

약간 길어지더라도 용도를 알기 쉽게 **의미 있는 이름**을 지어주는 습관을 들여보세요.

# 5. var
JDK 10부터는 매번 `int`, `String` 적기 귀찮을 때 **`var`** 를 쓸 수 있습니다. `var year = 2026;` 이라고만 적어도 컴파일러가 "아, 2026은 숫자니까 `int`다!"라고 알아듣죠. 단, 선언과 동시에 값을 꼭 넣어줘야 하고, **"지역 변수에서만 쓸 수 있다"** 는 점 기억해주세요.

## var 사용 예시
```java
// 컴파일러가 값을 보고 타입을 추론합니다.
var name = "tunachoi-dev";  // 오른쪽이 문자열이니 String으로 
var currentYear = 2026;  // 오른쪽이 정수니 int으로

// 선언된 이후에는 해당 타입처럼 똑같이 사용 가능합니다.
System.out.println(name + "의 연도는 " + currentYear);
```

## 주의해야 할 점 (에러가 나는 경우)
`var`는 편리하지만, 컴파일러가 타입을 추측할 수 있게 최소한의 힌트는 줘야 합니다.
```java
var age;  // 에러! 값을 안 넣으면 무슨 타입인지 알 수 없습니다.
var point = null;  // 에러! null만 봐서는 이게 숫자인지 문자인지 알 수 없습니다.
```
